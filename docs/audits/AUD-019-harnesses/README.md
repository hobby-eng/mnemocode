# AUD-019 harnesses

The scripts of [AUD-019](../AUD-019-2026-10-13.md), the full-scope audit of reviewed commit `6a0701507c9b01283b083b4840667683a08de10b`: the card redesign, word hints, the system sandbox and codes written apart or run together. The snapshot was captured as the uncommitted tree on `fa948b6a0ef651b14ce64d2dfc721b16d87f917d` and then committed unchanged. Run every command from the repository root after `pnpm install --frozen-lockfile`. They read the source and write only into the ignored `docs/audits/AUD-019-evidence/` and temporary folders under `../tmp/mnemocode/`, which they remove. Public test data only.
