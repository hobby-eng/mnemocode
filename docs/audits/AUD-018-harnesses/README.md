# AUD-018 harnesses

The scripts of [AUD-018](../AUD-018-2026-10-12.md), the full-scope audit of reviewed commit `fa948b6a0ef651b14ce64d2dfc721b16d87f917d` with the uncommitted candidate-file admission change. Run every command from the repository root after `pnpm install --frozen-lockfile`. They read the source and write only into the ignored `docs/audits/AUD-018-evidence/` and temporary folders under `../tmp/mnemocode/`, which they remove. Public test data only.

| Script | What it checks | Run | Expected output |
| --- | --- | --- | --- |
| `audit.py` | Records the environment, a source snapshot, or one command with its UTC times, exit code, log SHA-256, host memory and the source fingerprint before and after | `python3 docs/audits/AUD-018-harnesses/audit.py check LABEL [--timeout SECONDS] COMMAND ...` | The log's last lines and one JSON line; exits with the command's code, 124 when stopped |
| `run-checks.sh` | The baseline checks: `pnpm check`, format, build, ordinary tests (all but the 11 PDF-rendering files), CLI self-test, terminal check, package contents, advisories, private reporting | `sh docs/audits/AUD-018-harnesses/run-checks.sh` | Exit 0 when every check passes; each check has a `.log` and a `.command.json` |
| `readme-examples.py` | Runs the README's command examples that need no secret prompt and draw no PDF; needs `pnpm build` | `python3 docs/audits/AUD-018-harnesses/readme-examples.py` | One JSON line per command; exit 1 while an example fails (2 at this snapshot, see AUD-018-DOC001) |
| `probes.ts` with `probe.config.ts` | AUD-018-SEC001 through `decodeQrPngFile`, and its control through the text reader | `npx vitest run --config docs/audits/AUD-018-harnesses/probe.config.ts` | Before the fix one failing case and one passing control; after it both pass |
| `record-integrity.py` | Commit citations (in this history, in the sibling `multi-chain-wallet-tools` checkout, or explained by the index), duplicate JSON keys, finding IDs and index rows of every audit record; a missing link target is a warning | `python3 docs/audits/AUD-018-harnesses/record-integrity.py` | One JSON line per problem or warning; the audit's first version counted 15 problems at the reviewed snapshot, the remediated version finds 0 problems and 1 warning |
| `sskr-manifest.py` | The SSKR engine's files against `sskr-wasm/integrity.json`; no rebuild | `python3 docs/audits/AUD-018-harnesses/sskr-manifest.py` | `{"listed": 7, "problems": 0}`, exit 0 |
| `readme-secret-arguments.py` | Remediation of AUD-018-DOC001: every README example with `--ask-secrets` is accepted up to the terminal check (standard input from `/dev/null`, nothing asked or written); takes another README path | `python3 docs/audits/AUD-018-harnesses/readme-secret-arguments.py [README]` | `{"refused": 0}`, exit 0; on the text before the fix `{"refused": 2}`, exit 1 |
| `remediation-checks.sh` | The remediation snapshot and its checks: `pnpm check`, format, build, the 6 test files that read QR images, the CLI self-test, the probes, the README arguments and the record check | `sh docs/audits/AUD-018-harnesses/remediation-checks.sh` | Exit 0 |
| `remediation.py` | Adds the remediation addendum to both records and the index row from the remediation evidence; refuses to run twice | `python3 docs/audits/AUD-018-harnesses/remediation.py` | `addendum written; 8 checks` |
| `write-report.py` | Writes the Markdown and JSON report from one set of data and the local evidence; refuses to overwrite | `python3 docs/audits/AUD-018-harnesses/write-report.py` | The two file names |
| `validate-report.py` | Schema, both records, evidence hashes, procedure hashes, ledger, privacy, links, index; needs `jsonschema` and the sibling `multi-chain-wallet-tools` checkout | `python3 docs/audits/AUD-018-harnesses/validate-report.py` | One JSON line with `"outcome": "passed"`; writes `report-validation.json` and `SHA256SUMS` locally |

The probes and the record check failed on purpose while their findings were open; they are not part of the ordinary test collection. `run-checks.sh` first had `--timeout` before the label, which kept two checks from starting; it was corrected and both ran under their own labels, as the report says.
