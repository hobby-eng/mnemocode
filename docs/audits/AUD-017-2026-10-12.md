### Findings

#### AUD-016-API001 — Medium — Wallet snapshots still break host getters that read private class fields

- **Category:** API
- **Status:** open
- **Reproduction:** Return a WalletMatch-compatible class with matched:true, path:'m', private #derived and public get derived() returning it. Read derived after askWallet, then repeat through the actual WordCandidateSearch result.
- **Expected behavior:** The returned generic result retains readable supported host fields. Common checked fields remain one-read snapshots.
- **Observed behavior:** Common getters and ordinary derived fields work. A private-field getter throws 'Cannot read private member #derived from an object whose class did not declare it' both directly and from the word-search result.
- **Impact:** Object.create(given, captured fields) changes the getter receiver to a new object without the original class's private-field brand. A legitimate library/browser host can receive an unusable successful result. Built-in plain-object CLI answers were not shown to fail; no wrong-wallet approval or secret disclosure is demonstrated.
- **Recommended fix:** Preserve host result data with the original getter receiver, while retaining immutable one-read matched/path/warning values. Do not use a brandless prototype wrapper as if it were the original generic class instance.
- **Required verification:** Private-field-backed derived getter through askWallet and actual word-search output; ordinary own fields, prototype/non-enumerable fields, changing getters and malformed matched controls. Keep cancellation and cleanup regressions.
- **Release blocking:** true; Supported generic wallet results still become unusable; complete this public API remedy before release.
- **Affected files:** `src/core/wallet-check.ts` (SHA-256 `409487c7a2e382ed50c0238e11aff773cecd2d763ad2e7b355ccc15be376567b`)
- **Evidence:** `AUD-017-evidence/aud017-edges-confirmed.log`, SHA-256 `fce2ac92bbdeb7465e8b580f9a82545dd852f0113470bda87a3c7b3d9eebb487` (local only).
