### Findings

#### AUD-009-FUN001 — Low — The file collector trusts an external share-set label over the embedded identifier

- **Status:** open. **Release blocking:** false; the consequence is bounded and recovery/validation controls remain available.
- **Affected source / evidence:** `crates/mnemocode-embroidery/src/found.rs:269`; `docs/audits/AUD-009-harnesses/src/collector.rs:25`; `Local evidence: AUD-009-evidence/new-regressions-corrected.log`.
- **Reproduction:** Create two independently valid 2-of-3 public SSKR sets. Take member 1 from A and member 2 from B, label both card pages as set A, then collect the pages.
- **Expected:** Treat conflicting embedded set identifiers as a damaged/mixed set; do not advertise it as a usable quorum.
- **Observed:** The collector checks group topology and sizes but not info.identifier. It returns trouble=None for a set that restore_complete rejects with ConflictKind::Set. Fresh bounded regression reproduced this result after its positive controls passed.
- **Impact:** Folder discovery promises recovery that the recovery engine correctly refuses. This does not show reconstruction of an incorrect phrase or bypass of SSKR validation.
- **Recommended fix:** Validate embedded set identifiers and their correspondence to the external card label before merging.
- **Required verification:** Exercise genuine multi-group sets as a positive control, mismatched IDs as a negative control, and mixed metadata across all discovery sources.
- **Related earlier finding:** AUD-008-FUN002; distinct case, without duplicating the original symptom.

#### AUD-009-FUN002 — Low — A malformed surplus card share is silently discarded

- **Status:** open. **Release blocking:** false; the consequence is bounded and recovery/validation controls remain available.
- **Affected source / evidence:** `crates/mnemocode-embroidery/src/found.rs:439`; `docs/audits/AUD-009-harnesses/src/collector.rs:67`; `Local evidence: AUD-009-evidence/new-regressions-corrected.log`.
- **Reproduction:** Supply two valid shares of a 2-of-3 set and a third card page with a contiguous but truncated list containing only its first code.
- **Expected:** Restore using the valid quorum and report the damaged extra file.
- **Observed:** read_share errors are discarded by if let Ok; a contiguous short card list avoids the earlier missing-position error and does not produce a warning. Fresh bounded regression reproduced this result after its positive controls passed.
- **Impact:** The recoverable set remains usable, but a damaged backup silently appears unproblematic. The original complete-quorum failure was fixed; this is a distinct reporting omission.
- **Recommended fix:** Convert share-parsing errors into damaged-file notes while keeping the available quorum usable.
- **Required verification:** Test both a gap in card numbering and a contiguous invalid/truncated payload, with and without a complete valid quorum.
- **Related earlier finding:** AUD-008-FUN003; distinct case, without duplicating the original symptom.

#### AUD-009-FUN003 — Low — Repeated card exports with different decoys collide in discovery

- **Status:** open. **Release blocking:** false; the consequence is bounded and recovery/validation controls remain available.
- **Affected source / evidence:** `crates/mnemocode-cards/src/templates.rs:457`; `crates/mnemocode-cards/src/printed.rs:282`; `docs/audits/AUD-009-harnesses/src/cards.rs:14`; `Local evidence: AUD-009-evidence/new-regressions-corrected.log`.
- **Reproduction:** Export the same public 12-word Colors backup twice using business-it with independent synthetic decoy pools. Serialize the retained page metadata through xmp/pages_in and collect both exports.
- **Expected:** Both independently readable copies remain discoverable; differing decoys do not invalidate the real backup.
- **Observed:** The document ID depends on the real codes while the retained text also contains random decoys. Equal IDs with different decoy text become a Different conflict. Fresh bounded regression reproduced this result after its positive controls passed.
- **Impact:** A directory containing repeated valid exports can report an unreadable backup although either export alone works. This is a discovery failure, not demonstrated data corruption.
- **Recommended fix:** Give complete export instances suitable identities or explicitly distinguish invariant payload from variable decoration without suppressing real conflicts.
- **Required verification:** Check same-plan sheet/card merging, repeated exports with different decoys, exact copies, and genuine contradictory real codes.
- **Related earlier finding:** AUD-008-FUN007; distinct case, without duplicating the original symptom.

#### AUD-009-UI001 — Low — Returning to a completed Saving step resets the output checkboxes

- **Status:** open. **Release blocking:** false; the consequence is bounded and recovery/validation controls remain available.
- **Affected source / evidence:** `crates/mnemocode-cli/src/commands/new_backup.rs:283`; `crates/mnemocode-cli/src/commands/encode_questions.rs:496`; `crates/mnemocode-cli/src/terminal/choice.rs:657`.
- **Reproduction:** Change the Output checklist, finish the Saving questions, then navigate back from a later stage to Saving without changing the backup mode or form.
- **Expected:** Retain the selected destinations when revisiting this completed step.
- **Observed:** saved_where invokes ask_destination again, which initializes ticked from ticked_first. choose_many does not use the single-choice memory. Returning within the nested Saving questions does retain the ticks. Static trace; no dedicated PTY replay yet.
- **Impact:** Backtracking can replace explicitly chosen output destinations with defaults; the person can reselect them. The original child single-choice memory fix is independent.
- **Recommended fix:** Preserve the destination selection across calls, resetting only when incompatible form/mode changes require it.
- **Required verification:** PTY test that changes destinations, completes Saving, returns from the next stage, and verifies both ticks and generated destinations.
- **Related earlier finding:** AUD-008-UI001; distinct case, without duplicating the original symptom.
