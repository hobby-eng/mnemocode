MnemoCode 0.2.0 is the first release written in Rust. It is one executable for Linux, macOS or Windows with nothing else to install; on Linux it needs glibc 2.35 or later, as in Ubuntu 22.04 and Debian 12. It reads and writes every backup, record and share of 0.1.0, and its commands and questions stay the same.

What you will notice:

- Cards no longer need Poppler's `pdftocairo`.
- The menu explains each task and links to its section of the README.
- Secrets are wiped from memory and kept out of swap where the system allows it. A secret result is refused on a terminal without a private screen; files and pipes get it as before.
- Answers, files and standard input have limits, which `--help` names. A QR image may have up to 2 megapixels, enough for a 1920 × 1080 screenshot.
- Re-encode asks for the new backup before the old one.
- The npm package and the Node.js library are gone: the wallet-tools pages use this release's WebAssembly files.

PDF and PNG files have the same content as in 0.1.0, but different bytes. [CHANGELOG.md](https://github.com/hobby-eng/mnemocode/blob/v0.2.0/CHANGELOG.md) lists every change. The TypeScript version stays at [hobby-eng/mnemocode_typescript](https://github.com/hobby-eng/mnemocode_typescript) and gets fixes of critical defects only.

Check the download before you run it, as [Download verification](https://github.com/hobby-eng/mnemocode/blob/v0.2.0/docs/CLI.md#download-verification) explains.
