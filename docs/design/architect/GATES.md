# MnemoCode in Rust: gates

Every rule of `code-core` and `code-rust`, and the page rules that touch the WASM binding, mapped to
what enforces it and where it runs. The gates of `check` exist from increment 0 of PLAN.md, the
`pty` gate from increment 2, whose terminal it drives, and the release gates (`features`,
`artifacts`, `reproducible`, `executable`) from increment 11, whose tooling they run; an empty
workspace passes each from its increment on, and every later change keeps them green.

## Where gates run

- **check**: `scripts/check.sh`, the fast gates of CORE-43, run before every commit; CI runs the
  same script on every push (Linux, CI-04).
- **release**: `scripts/verify.sh` on a release tag or a manual dispatch, on Linux, macOS and
  Windows: everything of check, plus the slow and per-system gates.

TOOL-03 and TOOL-05 (the tooling `package.json` that Prettier and the Node scripts and tests run
